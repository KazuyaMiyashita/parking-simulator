# インプレッサ SPORT 駐車シミュレーター (Unity)

自分の車 **SUBARU インプレッサ SPORT(GT2F54C / FF / CVT / クリスタルホワイト・パール)** の寸法と最小回転半径を再現して、
いろいろな駐車場のケースで駐車の練習・確認ができる PC 向けシミュレーターです。

| 項目 | 値 |
|---|---|
| 全長 × 全幅 × 全高 | 4,475 × 1,775 × 1,480 mm |
| ホイールベース / トレッド(前・後) | 2,670 / 1,540・1,545 mm |
| 最小回転半径 | 5.3 m(ハンドルいっぱいで外側前輪がえがく円の半径) |
| ステアリング | ギア比 13.0、片側 約455°(ロック・トゥ・ロック 約2.5回転) |

全長・全幅・最小回転半径は指定どおりの値です。それ以外(ホイールベース、トレッド、オーバーハング、ギア比、タイヤ径など)はカタログ値に近い想定値で、`Assets/ParkingSimulator/Scripts/CarSpec.cs` で変更できます。

## 起動方法

1. Unity Hub で `parking-simulator` フォルダを開く(Unity **6000.0.56f1** で作成。Built-in レンダーパイプライン)
2. `Assets/Scenes/ParkingSimulator.unity` を開いて ▶ 再生
   - シーンが無い場合はメニュー **Parking Simulator → シーンを作成して開く**
   - 空のシーンで再生しても自動でシミュレーターが起動します
3. 単体アプリにする場合: メニュー **Parking Simulator → Mac 用にビルド / Windows 用にビルド**(`Builds/` に出力)

最初に設定メニューが開くので、スタート地点を選んで「この地点からスタート」を押します。
車はエンジン停止状態から始まります。ブレーキを踏みながら Joy-Con の L(キーボードは I)を長押しするとエンジンが始動し、シフト P になります。

## 視点

- **2D 俯瞰**: 真上から見下ろす。予想進路線(黄=進行方向側の角、水色=反対側の角)と、自宅の車庫・月極の契約区画の枠(水色)を表示。車の向きが常に画面の上。ズーム・広域表示可
- **3D 運転席**: 右ハンドルの運転席の目線。ピラー・ダッシュボード・ハンドル(12時に橙の目印)・ドアミラー・ルームミラーあり。
  ミラーは画面上にも拡大表示。R に入れるとドアミラーが下を向きます(リバース連動ドアミラー)
- **3D 外から**: 常に車の後ろ上方から(Joy-Con の左スティック上下で仰角、左右で回り込み)。建物や他の車で車が隠れるときは自動で高い位置から映します

R に入れると**バックモニター**(距離目安線 0.5m 赤 / 1m 黄 / 2・3m 緑 + ハンドル連動の予想進路線)と**距離センサー**が表示されます。

## 世界(マップ)

時間が止まった町で、自分だけが運転の練習をできる設定です。歩行者や走っている車はいません(停まっている車はあります)。

町は外周道路(約225m × 150m)で囲まれ、行き止まりはありません。中央の十字路のほかはすべて T字路です。

- **幹線道路**: 外周道路と、町を東西・南北に貫く道路A・B(片側1車線・左側通行・歩道あり)。A と B の十字路には信号機(消灯)・横断歩道・停止線。T字路には停止線。路上駐車の車も数台
- **生活道路**(1車線・縁石あり): 各ブロックを抜ける細い道。入口は少し広がっています
  - **S字の抜け道**(北東, 道幅3.6m): 道路A → 北の外周。半径9mの S字
  - **クランクの路地**(南東・北西, 道幅3.6m): 直角カーブが4つ
  - **北の生活道路**(道幅4m): 縦列駐車帯(5台分)がある
  - **コンビニ裏の生活道路**・**自宅前の生活道路**(道幅4m)
- **自宅**(南西): 生活道路に面した戸建ての車庫(内寸 幅3.0m × 奥行6.0m、両側と奥が塀、輪止めあり)。奥の壁に青い札。お隣の家も車庫付き
- **月極駐車場**(南西): 区画の幅2.3mと車間が狭い。自分の契約区画(奥の壁に青い札)が1つ
- **コンビニ**(南東)・**スーパー**(北東): 区画の幅2.8mで車間が広い。スーパーは4列53区画

歩道やコースの縁石にタイヤが当たると、速度が落ちて段差に乗り上げ(車体が傾きます)、「脱輪」として数えます。車体やミラーが他の車・壁・ポール・電柱・建物などに当たると「接触」で、その場で停止します。

設定メニューで**スタート地点**を選べます(自宅の車庫 / 交差点の手前 / 月極駐車場 / コンビニ駐車場 / スーパー駐車場 / 縦列駐車帯 / S字の抜け道の入口 / クランク(南東・北西)の入口)。どこも停車した状態から始まり、F5 で選んだ地点に戻ります。

## 操作

| キー | 操作 |
|---|---|
| W / ↑ | アクセル(押している間に踏み込み量が増える) |
| S / ↓ | ブレーキ(軽く押すとクリープ速度を調整) / Space 強くブレーキ |
| A D / ← → | ハンドル(Shift で速く回す) / C ハンドルを中立に戻す |
| M | マウスハンドル(マウスの左右位置がハンドル角) |
| 1 2 3 4 | シフト P R N D(Q / E で1段ずつ)。停止中のみ切替可 |
| B | 電動パーキングブレーキ(アクセルで自動解除) |
| ブレーキ + I 長押し | エンジン始動(停止中) / エンジン停止(P のとき) |
| V / Tab | 視点切替 |
| 2D: ホイール / + - , F | ズーム、広域表示 |
| 3D: 右ドラッグ, Z, X, Z+X, ホイール | 見回す、左を見る、右を見る、振り返る、視野角 |
| G / K / O / L | 予想進路線 / バックモニター / センサー音 / 位置ガイド |
| Enter | 近くの駐車枠で判定(エンジンを止めても自動判定) |
| F5 / Backspace | スタート地点へ戻る |
| N | マップ(目的地を選ぶ。開いている間はゲームの時間が止まる) |
| Esc / F1, H | 設定メニュー(開いている間はゲームの時間が止まる)、操作説明 |

D / R に入れてブレーキを離すとクリープ(前進 約6km/h・後退 約5km/h)で動きます。クリープは初期設定では OFF で、設定メニューで ON にできます。

### Joy-Con (L)+(R) / ゲームパッド

L と R を左右の手に1本ずつ持つ想定です。プロコンなどのゲームパッドも同じ配置で使えます(設定メニューはスタートボタン)。

| 操作 | 内容 |
|---|---|
| 左の ▲ / ▼ | アクセル / ブレーキ(押している間に踏み込み量が増える) |
| 右スティック 左 / 右 | ハンドルを回す(倒した量に比例した速さ)。離すと手を離したハンドルのように中立へ戻る |
| R(押している間) | ハンドルの切れ角を保持(スティックを離しても戻らない) |
| L / ZL | シフトを1段ずつ D 側 / P 側へ(P → R → N → D) |
| ▼ + L 長押し | エンジン始動(エンジン停止中。シフトは P) |
| ▼ + ZL 長押し | エンジン停止(シフト P のとき)。駐車枠の近くなら判定 |
| ZR | 視点切替 |
| 左スティック | 3D 運転席: 倒している間だけその方向を見る(離すと正面) / 3D 外から: 上下で仰角(離してもそのまま)、左右で回り込み(離すと後方に戻る) / 2D: ズーム |
| 左スティック押し込み | 3D 外からは仰角を、2D はズームを初期値に戻す |
| キャプチャーボタン(左の Joy-Con の丸いボタン) | 設定メニュー(一時停止) |
| − ボタン | マップ(一時停止)。十字 / スティックで区画を選び、A で目的地に決定、X でおまかせ、Y で目的地をやめる、− / B で閉じる |

判定結果は、エンジンをかけるか車が動き出すと自動で閉じます。

## 判定

駐車枠(自宅の車庫、月極・コンビニ・スーパーの区画、縦列駐車帯)の近くでエンジンを止める(または Enter)と、いちばん近い枠に対して
左右の白線(縁石)内側までの余白・角度のずれ・通路へのはみ出し(縦列は縁石までの距離)・接触・脱輪・切り返しの回数から 100 点満点で採点します。
接触などの回数は、その枠に近づいてからの分だけを数えます。前向き・バックどちらで停めても判定できます(縦列は進行方向向き)。
運転中も画面左上の「位置ガイド」で左右の余白と角度を確認できます。

## 目的地ゲーム

マップ(Joy-Con の − ボタン / N キー)を開き、空いている駐車区画(自宅の車庫、月極の契約区画、コンビニ・スーパーの駐車場、縦列駐車帯)から目的地を選びます。
目的地には地面のオレンジの枠と浮かんだ目印が出て、画面右上に方向の矢印と直線距離が表示されます。
目的地に停めてエンジンを切る(または Enter)と「目的地に到着!」として採点し、道のり・所要時間・道中の接触と脱輪、区画ごとの自己ベストを表示します。
結果画面の「次の目的地」からすぐに次を選べます。自己ベストはアプリを終了するまで残ります。

## 構成

```
Assets/ParkingSimulator/
  Scripts/
    CarSpec.cs            車両寸法と運動学(後輪中心の二輪モデル、アッカーマン)
    CarController.cs      ペダル・CVT クリープ・シフト・ステアリング・接触判定
    VehicleBuilder.cs     自車(外装・内装・ミラー・バックカメラ)と駐車中の他車
    World.cs              駐車枠・スタート地点・区域の定義
    WorldBuilder.cs       世界全体の生成
    TownBuilder.cs        町(幹線道路と交差点・生活道路の S字/クランク・自宅・月極・コンビニ・スーパー・家並み)
    BuildKit.cs           白線・縁石・歩道・駐車区画の列などの部品
    JoyConHID.cs          Joy-Con の HID ドライバー(フル入力モードでスティックを読む)
    Pad.cs                Joy-Con / ゲームパッドの入力のまとめ
    CameraRig.cs          2D 俯瞰 / 3D 運転席 / 3D 外部 の視点とミラー
    ParkingSensors.cs     距離センサーと警告音(接触音は3秒で止まる)
    MapView.cs            町全体のマップと目的地の候補選び
    DestinationMarker.cs  目的地の目印
    CarAudio.cs           エンジン音(水平対向+CVT)・セルモーター・ブレーキ音の合成
    PathGuide.cs          予想進路線
    ParkingJudge.cs       駐車判定
    HUD.cs                画面表示と設定メニュー
    GameManager.cs        全体管理
  Editor/ParkingSimEditor.cs   シーン作成・ビルド用メニュー
  Resources/                   ベースマテリアル、日本語フォント(BIZ UDPゴシック, SIL OFL 1.1)
```

外部アセットは使わず、車や駐車場はすべて実行時にプリミティブから生成しています。
