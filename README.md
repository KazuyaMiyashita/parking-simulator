# インプレッサ SPORT 駐車シミュレーター (Unity)

自分の車 **SUBARU インプレッサ SPORT(GT2F54C / FF / CVT / クリスタルホワイト・パール)** の寸法と最小回転半径を再現して、
いろいろな駐車場のケースで駐車の練習・確認ができる PC 向けシミュレーターです。

| 項目 | 値 |
|---|---|
| 全長 × 全幅 × 全高 | 4,475 × 1,775 × 1,480 mm |
| ホイールベース / トレッド(前・後) | 2,670 / 1,540・1,545 mm |
| 最小回転半径 | 5.3 m(ハンドルいっぱいで外側前輪がえがく円の半径) |
| ステアリング | ギア比 13.0、片側 約455°(ロック・トゥ・ロック 約2.5回転) |

全長・全幅・最小回転半径は指定どおりの値です。それ以外(ホイールベース、トレッド、オーバーハング、ギア比、タイヤ径など)はカタログ値に近い想定値で、`Assets/ParkingSimulator/Scripts/CarSpec.cs` で変更できます。

## 起動方法

1. Unity Hub で `parking-simulator` フォルダを開く(Unity **6000.0.56f1** で作成。Built-in レンダーパイプライン)
2. `Assets/Scenes/ParkingSimulator.unity` を開いて ▶ 再生
   - シーンが無い場合はメニュー **Parking Simulator → シーンを作成して開く**
   - 空のシーンで再生しても自動でシミュレーターが起動します
3. 単体アプリにする場合: メニュー **Parking Simulator → Mac 用にビルド / Windows 用にビルド**(`Builds/` に出力)

最初に設定メニューが開くので、スタート地点を選んで「この地点からスタート」を押します。

## 視点

- **2D 俯瞰**: 真上から見下ろす。予想進路線(黄=進行方向側の角、水色=反対側の角)と、自分の区画・教習所の車庫や縦列の枠(水色)を表示。ズーム・広域表示可
- **3D 運転席**: 右ハンドルの運転席の目線。ピラー・ダッシュボード・ハンドル(12時に橙の目印)・ドアミラー・ルームミラーあり。
  ミラーは画面上にも拡大表示。R に入れるとドアミラーが下を向きます(リバース連動ドアミラー)
- **3D 外から**: 常に車の後ろ上方から

R に入れると**バックモニター**(距離目安線 0.5m 赤 / 1m 黄 / 2・3m 緑 + ハンドル連動の予想進路線)と**距離センサー**が表示されます。

## 世界(マップ)

時間が止まった町で、自分だけが運転の練習をできる設定です。歩行者や走っている車はいません(停まっている車はあります)。

- **自宅の月極駐車場**(南西): 中央通路の両側に U字の区画と輪止め。いろいろな車が停まっています。自分の区画(奥の壁に青い札)に P・パーキングブレーキ ON で停車した状態から始まります
- **公道**: 東西と南北の道路(片側1車線・左側通行・歩道あり)が十字に交わる交差点。信号機(消灯)・横断歩道・停止線があります。路上駐車の車も数台
- **コンビニ**(南東): 店の前の駐車場(I字の区画)
- **自動車教習所**(北東): S字(道幅3.6m)、クランク(道幅3.5m)、方向転換(車庫入れ)、縦列駐車(ポール付き)、教習所の駐車場

歩道やコースの縁石にタイヤが当たると止まり、「脱輪」として数えます。車体やミラーが他の車・壁・ポール・電柱などに当たると「接触」です。

設定メニューで**スタート地点**を選べます(自宅の駐車スペース / 交差点の手前 / 自宅駐車場の出口 / コンビニ駐車場 / 教習所の入口・S字・クランク・方向転換・縦列駐車・駐車場)。どこも停車した状態から始まり、F5 で選んだ地点に戻ります。

## 操作

| キー | 操作 |
|---|---|
| W / ↑ | アクセル(押している間に踏み込み量が増える) |
| S / ↓ | ブレーキ(軽く押すとクリープ速度を調整) / Space 強くブレーキ |
| A D / ← → | ハンドル(Shift で速く回す) / C ハンドルを中立に戻す |
| M | マウスハンドル(マウスの左右位置がハンドル角) |
| 1 2 3 4 | シフト P R N D(Q / E で1段ずつ)。停止中のみ切替可 |
| B | 電動パーキングブレーキ(アクセルで自動解除) |
| V / Tab | 視点切替 |
| 2D: ホイール / + - , F | ズーム、広域表示 |
| 3D: 右ドラッグ, Z, X, Z+X, ホイール | 見回す、左を見る、右を見る、振り返る、視野角 |
| G / K / O / L | 予想進路線 / バックモニター / センサー音 / 位置ガイド |
| Enter | 近くの駐車枠で判定(P に入れても自動判定) |
| F5 / Backspace | スタート地点へ戻る |
| Esc / F1, H | 設定メニュー(開いている間はゲームの時間が止まる)、操作説明 |

D / R に入れてブレーキを離すとクリープ(前進 約6km/h・後退 約5km/h)で動きます。

### Joy-Con (L)+(R) / ゲームパッド

L と R を左右の手に1本ずつ持つ想定です。プロコンなどのゲームパッドも同じ配置で使えます(設定メニューはスタートボタン)。

| 操作 | 内容 |
|---|---|
| 右スティック 上 / 下 | アクセル / ブレーキ。倒した量に比例して踏み込み、スティックを離しても踏み込み量はそのまま |
| 右スティック 左 / 右 | ハンドルを回す(倒した量に比例した速さ) |
| 右スティック押し込み | アクセル・ブレーキ・ハンドルを、人が戻せる程度の速さでゆっくり中立に戻す |
| A / B | アクセル / ブレーキ(押している間だけ) |
| L / ZL | シフトを1段ずつ D 側 / P 側へ(P → R → N → D) |
| 左スティック | 視線を動かす(3D 運転席は見回し、3D 外からは回り込み、2D はズーム)。離してもそのまま |
| 左スティック押し込み | 視線を正面に戻す |
| キャプチャーボタン(左の Joy-Con の丸いボタン) | 設定メニュー(一時停止) |

判定結果は、シフトを P から動かすか車が動き出すと自動で閉じます。

## 判定

駐車枠(自宅・コンビニ・教習所の区画、方向転換の車庫、縦列駐車の枠)の近くで P に入れる(または Enter)と、いちばん近い枠に対して
左右の白線(縁石)内側までの余白・角度のずれ・通路へのはみ出し(縦列は縁石までの距離)・接触・脱輪・切り返しの回数から 100 点満点で採点します。
接触などの回数は、その枠に近づいてからの分だけを数えます。前向き・バックどちらで停めても判定できます(縦列は進行方向向き)。
運転中も画面左上の「位置ガイド」で左右の余白と角度を確認できます。

## 構成

```
Assets/ParkingSimulator/
  Scripts/
    CarSpec.cs            車両寸法と運動学(後輪中心の二輪モデル、アッカーマン)
    CarController.cs      ペダル・CVT クリープ・シフト・ステアリング・接触判定
    VehicleBuilder.cs     自車(外装・内装・ミラー・バックカメラ)と駐車中の他車
    World.cs              駐車枠・スタート地点・区域の定義
    WorldBuilder.cs       世界全体の生成
    TownBuilder.cs        公道・交差点・信号・自宅の月極駐車場・コンビニ・家並み
    SchoolBuilder.cs      自動車教習所(S字・クランク・方向転換・縦列駐車・駐車場)
    BuildKit.cs           白線・縁石・歩道・駐車区画の列などの部品
    JoyConHID.cs          Joy-Con の HID ドライバー(フル入力モードでスティックを読む)
    Pad.cs                Joy-Con / ゲームパッドの入力のまとめ
    CameraRig.cs          2D 俯瞰 / 3D 運転席 / 3D 外部 の視点とミラー
    ParkingSensors.cs     距離センサーと警告音
    PathGuide.cs          予想進路線
    ParkingJudge.cs       駐車判定
    HUD.cs                画面表示と設定メニュー
    GameManager.cs        全体管理
  Editor/ParkingSimEditor.cs   シーン作成・ビルド用メニュー
  Resources/                   ベースマテリアル、日本語フォント(BIZ UDPゴシック, SIL OFL 1.1)
```

外部アセットは使わず、車や駐車場はすべて実行時にプリミティブから生成しています。
