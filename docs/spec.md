# インプレッサ駐車シミュレーター 新仕様

旧仕様の記録は [current-spec.md](current-spec.md) にあります。この文書は作り直し後の仕様です。

## 1. 目的

- 自分の車(SUBARU インプレッサ SPORT)が駐車のときにどう動くかを確かめる。何回切り返しが要るか、どう操作すると接触するかを体で覚える。
- 最終的な目標は、実車で駐車の事故を起こさないこと。
- 点数や判定は付けない。ストレスなく長く遊べることを優先する。目標は「事故なく目的地に着くこと」で、上達は経験から得る。

## 3. ゲームの流れ

1. 自宅のカーポート(駐車スペース 中)に P で停まった状態から始まる。エンジンの始動・停止の操作はなく、始動音も鳴らさない。
2. マップ(カーナビ相当)で目的地を選ぶ。選ばずに好きなところへ行ってもよい。マップは止まっているときだけ開ける。
3. 目的地を選ぶと、マップに印と経路の線を引く。運転中は経路に沿って曲がり角ごとに案内する(下記)。道を覚えることは求めない。
4. どこかの駐車枠に収まった状態で P に入れると「到着」。駐車回数と総走行距離を表示する。

### カーナビ

- 経路を道の中心線のつながりから計算し、向きが 35° 以上変わる所を右左折とする。
- 画面右上に、次の曲がり角の向き(矢印)・そこまでの道のり・目的地までの道のりを出す。
- 音声で読み上げる(macOS は日本語音声 Kyoko、Windows は OS の音声合成): 案内開始、「この先、およそ○メートル直進です」(150m より先に曲がり角があるとき)、「およそ○メートル先、右方向です」(120m 以内)、「まもなく右方向です」(25m 以内)、「まもなく目的地です」(残り 18m)、「○○に到着しました」。
- 目的地の空いている駐車枠を、オレンジの枠と薄い塗りで少し目立たせる(以前の浮かぶひし形の目印はなし)。

### 到着の判定

- P に入れた瞬間に、車体の四隅がすべて駐車枠(白線の内側)に入っていれば到着。駐車回数を1増やし、駐車回数と総走行距離を表示する。
- 車体の一部だけが枠に入っているときは、「車体が枠からはみ出しています」と表示する。
- それ以外の場所で P に入れたときは何も表示しない。
- 目的地を選んでいたかどうか、自宅かどうかに関係なく数える。地図での選択はカーナビの設定にすぎない。
- 同じ場所で P に入れ直して回数を稼げないよう、前回の駐車から 3m 以上走ったときだけ数える。

### 目的地と解放

| エリア | 場所 | 駐車スペース | 状態 |
|---|---|---|---|
| 近く | 自宅(カーポート) | 中 2.5m | 実装済み |
| 近く | 近所のコンビニ | 広い 3.0m | 実装済み |
| 近く | ちょっと遠くのスーパー | 中 2.5m | 実装済み |
| 近く | よく行くお店(旧 月極駐車場) | 狭い 2.3m | 実装済み |
| 遠く | 友達の家(2台分。片方に友達の車) | 中 2.5m | 未実装 |
| 遠く | よく行くお店2(行くまでの道が狭い。道幅 3.0m) | 中 2.5m | 未実装 |
| 遠く | よく行くお店3(道は普通だが遠い) | 狭い 2.3m | 未実装 |

- 駐車枠の奥行きは 5.0m。枠の幅は白線の中心間。
- 近くの3か所(コンビニ・スーパー・よく行くお店)に一度ずつ停めると、遠くのエリアへの通行止めの柵が消え、マップでも選べるようになる。
- 自宅以外の6か所すべてに一度でも停めるとクリア。クリア後も自由に目的地を決めて運転できる。

### 接触

- 車体が他の車・壁・柱に接触したら、知らせて車をその場で止める。警告音は3秒で止まる。
- 振り返りや「数秒前に戻る」などの教育的な表示はしない。
- 縁石は事故扱いにせず、乗り上げて車体が傾き、速度が落ちる。

## 4. 操作

Joy-Con とキーボードで同じ操作ができる。違いはスティックの角度(連続値)だけ。片方の機器でしかできない操作は作らない(マウス操作もなし)。

| 操作 | Joy-Con | キーボード |
|---|---|---|
| アクセル / ブレーキ | A / B | W / S |
| ハンドル | 左スティック左右 | A / D |
| ハンドル固定(切り替え) | ZL | Space |
| シフト P→R→N→D / 逆 | R / L | E / Q |
| 見渡す | 右スティック | 矢印キー |
| 視点切替 | ZR | V |
| マップ / メニュー | − / + | M / Esc |
| 画面内: 選ぶ / 決定 / 戻る | 左スティック・十字 / A / B | 矢印・WASD / Enter・Space / Backspace |

- パーキングブレーキはなし(町は平らなので P で止まる)。
- ペダルはデジタル入力なので、押している間に踏み込み量が増える。
- シフト操作にブレーキは要らない。走行中の危険な切り替え(動いている間の P、前進中の R、後退中の D)だけ断る。
- 計器の P R N D の左右に「L / Q ◀」「R / E ▶」を表示して、シフトのキーと動く向きの対応を示す。

### ハンドル

- スティックを倒した角度がハンドルの目標角になり、ハンドルはその角度まで現実的な速さ(約 540°/秒)で回る。キーは押している間、いっぱいまで回る。
- 離すと中央へ徐々に戻る(走っているほど速く戻る)。
- ZL(Space)で今の角度に固定する。固定中は手を離しても角度を保つので、駐車に専念できる。
- 固定は、もう一度 ZL(Space)を押すか、スティック(キー)をいったん離してから倒し直すと解除される。倒し直した場合は、そのまま新しい角度へつかみ直す。

## 5. 視点

ZR(V)で 車外の三人称(既定)→ 運転席の一人称 → 真上からの 2D → 車外の三人称 の順に切り替わる。

| 視点 | 見渡す操作(右スティック / 矢印) |
|---|---|
| 車外の三人称 | 上下で仰角(離してもそのまま)、左右で回り込み(離すと後方に戻る)。建物などで車が隠れるときは自動で仰角を上げる |
| 運転席 | 倒している間その方向を見る。離すと正面に戻る。ミラー3面を画面に表示 |
| 2D | 上下でズーム。車の向きが常に画面の上 |

## 6. 補助表示

| 表示 | 既定 | 備考 |
|---|---|---|
| バックカメラ | R のとき常に表示(三人称・一人称) | 実車と同じく、ハンドルに連動するガイド線つき |
| 距離センサー(前後) | 常に表示 | 実車にはないが学習のために残す |
| 予想進路線(車体の四隅の軌跡) | 常に表示 | R のときは後ろ、それ以外は前へ進んだときの線。すべての視点で見える |
| 他の車などとの距離(3D) | OFF | 車体と障害物の一番近い点を線で結び、cm で表示。実際に試して残すか決める |
| 余白の数値(2D テキスト) | 削除 | |
| 真上の補助カメラ | 削除 | 2D 視点に統合 |

## 7. メニュー

運転に戻る / 車の選択 / クリープ現象(既定 OFF)/ センサー音 / 他の車などとの距離(3D)/ 音量 / 操作説明 / 自宅に戻る / 記録をリセット(2回決定)/ ゲームを終了

- 車の選択: 枠は3つ。1つ目がインプレッサ(外観のプレビューと諸元・最小回転半径を表示)。残り2つは中身なし。
- メニュー・マップを開いている間は、ゲームの時間と音(エンジン音・音声案内も)を止める。

## 8. 記録

`save.json`(Application.persistentDataPath)に保存する: 駐車回数、総走行距離、到着した場所、クリア済みか、設定。

## 9. 削除したもの

エンジンの始動・停止操作、点数・ランク・自己ベスト・減点の説明、Enter での手動判定、スタート地点の選択、F5 のやり直し、パーキングブレーキ、マウス操作すべて、シフトの直接選択(1〜4)、強くブレーキ(Space)、Shift でハンドルを速く回す、補助機能の個別キー(G / K / O / L / H)、2D の広域表示(F)、ホイールでのズーム・視野角、Z / X の目視、ハンドル保持の長押し(R)。

## 11. 音

すべてその場で合成する(音声ファイルなし)。

| 音 | 作り方 |
|---|---|
| 始動 | なし |
| エンジン | ごく小さなこもったアイドル音(燃焼パルスを 45 / 90Hz の共鳴に通す)。アクセルを踏んでも吹かす音にはせず、回転は最大でも +700rpm 程度 |
| 走行 | CVT のかすかなうなりとロードノイズ(速度に比例) |
| ブレーキ | 急ブレーキ(踏み込み 75% 以上、約 5km/h 以上)のときだけ「キーッ」と鳴く。普段のブレーキは無音 |
| 接近 | 倍音を混ぜたベル調の短い音。前のセンサーは高め(約 2.1kHz)、後ろは低め(約 1.6kHz)。近いほど間隔が短く、30cm 未満で連続音 |
| 接触 | 近い2つの高さを重ねた連続音。3秒で止まる |
| R のお知らせ | 約 1.1 秒ごとの「ポーン」(約 1.3kHz)。センサーが鳴っている間は鳴らさない |
